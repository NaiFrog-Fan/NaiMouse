# 奶鼠 NaiMouse

奶鼠是一只调皮又爱装乖的小黄鼠，嘴角藏着坏主意，尾巴总会出卖它。

这是一款 Codex 自定义宠物，采用奶黄色的立体玩具风格，包含 **9 组动作和 16 个视线方向**。当前版本使用小幅度的蹦跳微笑，以及双脚交替迈步的左右跑步动画。

![奶鼠蹦跳预览](preview/jumping.gif)

## 安装

1. 将 `NaiMouse-Codex-Pet.zip` 完整解压。
2. 在 Codex 的宠物设置中打开自定义宠物目录。
3. 将解压后的 `naimouse` 文件夹整体复制到该目录。
4. 返回宠物设置，点击 **刷新**，然后选择 **奶鼠**。

默认安装位置为 `~/.codex/pets/naimouse/`；Windows 下通常为 `%USERPROFILE%\.codex\pets\naimouse\`。如果设置了 `CODEX_HOME`，则使用该目录下的 `pets/naimouse/`。

安装后的文件结构应为：

```text
naimouse/
├── pet.json
└── spritesheet.webp
```

更新已有奶鼠时，替换上述两个文件后刷新并重新选择奶鼠。

## 预览

用浏览器打开 [preview/index.html](preview/index.html)，即可离线查看全部动作，切换深浅背景，并体验十六个方向的视线跟随。请保留 `preview` 与 `naimouse` 两个文件夹的相对位置。

预览页中的按钮用于手动试播；实际宠物的动作由 Codex 根据互动和任务状态切换。

## 动作与触发方式

| 动作 | 触发方式 |
| --- | --- |
| 装乖待机 | 没有需要展示的任务状态或互动时 |
| 偷偷向右溜 | 按住奶鼠向右拖动 |
| 偷偷向左溜 | 按住奶鼠向左拖动 |
| 眨眼打招呼 | 首次唤醒宠物时的问候 |
| 得意一蹦 | 鼠标移入奶鼠身体的互动区域 |
| 被抓包了 | 任务失败或发生系统错误，显示 Blocked |
| 求你放行 | 需要审批、回答问题或作决定，显示 Needs input |
| 琢磨小主意 | 有聊天正在执行任务，显示 Running |
| 仔细检查 | 任务已完成且有未读结果，显示 Ready |
| 跟着你看 | 根据可用注视目标切换十六个方向；直接悬停在身体上时会触发蹦跳 |

多任务状态的展示优先级为：**需要输入 → 受阻 → 已就绪 → 工作中**。拖动和悬停会临时覆盖任务动作，部分动作播放数轮后会恢复慢速待机。

以上触发说明于 2026 年 10 月 1 日核对本机版本 `26.928.3736.0`，具体表现可能随客户端版本变化。更多说明见 [官方宠物文档](https://learn.chatgpt.com/docs/pets) 和包内的 [动作触发说明.txt](动作触发说明.txt)。

- 显示名称：奶鼠
